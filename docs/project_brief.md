# Project Brief

## Research Question
At today's market price, is FPT undervalued, fairly valued, or overvalued, and which assumptions drive that conclusion?

## Why FPT
I chose FPT because I see it as a strong, 
well-run company with a record of profits, and I will test that with six years of audited data. 
A good company is not always a good investment, because price matters. FPT also has several segments 
(technology, telecom, education), which makes it a good case for learning equity analysis for a research analyst 
role.

## Scope
- Period: 2020-2025 (to confirm the latest audited report)
- Data: audited consolidated financial statements
- Core peers: CMG, Infosys, TCS
- Extended peers (robustness check): HCLTech, Wipro

## Method
1. Ratio analysis and DuPont
2. Business and financial risk analysis (CV of sales and EBIT, DOL, DFL, DTL, interest coverage)
3. Forecast in three scenarios (conservative, base, optimistic)
4. Valuation: DCF and P/E, EV/EBITDA
5. Sensitivity analysis

## Tools
- **Excel:** analysis, forecast, DCF
- **SQL:** store and query data
- **Python:** data cleaning, beta/CAPM, cross-checks
- **Power BI:** one-page dashboard

## Deliverables
Source data table, Excel model, SQL database, Python scripts, dashboard, short report.

## Limitations
- Foreign peers use different accounting standards and currencies, so only ratios are compared.
- Forecasts rest on assumptions and are not predictions.
- Market inputs change over time, so each one is dated.
- Risk measures use few annual observations (quarterly data added), and DOL is an empirical estimate because fixed and variable costs are not disclosed.
- This is a learning project, not investment advice.
